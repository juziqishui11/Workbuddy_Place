# 个人工作任务台

一个自包含的单文件 Web 应用，用于管理多项目并行 + 日常任务 + 临时事项，所有数据保存在浏览器本地。

## 用法

**直接使用（双击）**：浏览器打开 `index.html` 即可。所有功能离线可用，只有「概览页天气」需要联网（Open-Meteo 免 key 公开接口）。

**重新构建**（可选）：
```bash
node build.mjs
```
读取 `src/` 下的所有源文件，拼出 `index.html`。如果只想用现成的，`index.html` 本身已经完整、不依赖任何外部资源。

## 数据管理

- 数据键名：`localStorage["wd_workbench_v1"]`
- 写入失败（隐私模式 / 空间不足）→ 弹 toast 提示「本地存储不可用」
- 导入文件前 → 校验 version / 字段类型 / id 完整性，**不通过则拒绝导入并显示具体原因**
- 恢复备份前 → 二次确认是否覆盖
- 数据损坏 → 弹窗提供「下载损坏副本 / 重置」两个按钮
- 清空全部数据 → 二次确认，需手动输入「清空」两字

## 已知边界

- localStorage 容量上限（~5 MB / 来源）：数据量极大时会失败，备份窗口会弹 toast 提示
- 浏览器跨域：天气接口（Open-Meteo）已设 `Access-Control-Allow-Origin: *`，可直接跨源；本地 `file://` 协议下若浏览器拦截跨源会降级显示「天气暂不可用」
- 任务截止时间如果只填日期不填时间 → 按当天 23:59 计；用于「逾期」判定
- 「自然周」以周一为起点（与 JS `Date.getDay()` 一致）
