# 小程序案例指引 · 口袋卡牌助手（宝可梦单 IP）

> 对应「工具与案例」模块案例：**口袋卡牌助手小程序**
> 仓库：`https://github.com/juziqishui11/Workbuddy_Place/tree/main/toy-collection-mp`

## 这个案例解决什么

把「宝可梦卡牌收藏」做成可随手记录的私人卡牌册小程序，主打 **宝可梦单 IP 主题**（对标「口袋卡牌助手」效果）：

- 关都地区 151 只宝可梦完整图鉴，卡牌图取自 PokeAPI 官方精灵图（远程加载、带兜底）。
- 收藏墙（我的卡牌）、全图鉴（卡册）、开包模拟（开包）三件套 + 个人中心（我的）。

## 它能演示的小程序能力

- 原生微信小程序完整骨架（app + 6 个 page：index/dex/detail/add/gacha/settings）
- 本地存储读写（`wx.getStorageSync`）：收藏/心愿完全离线，无需服务器
- 配置驱动 UI：数据源统一在 `data/pokemon.js`，页面零改动即可换数据
- 列表/卡片/进度条/表单/弹窗 等常见交互组件
- **开包模拟**：加权随机抽卡（传说/幻之稀有掉落、未拥有加权推进图鉴），翻牌动画，抽到的卡自动点亮收藏册

## 怎么预览（3 步）

1. 装 **微信开发者工具** → 「导入项目」选 `toy-collection-mp` 文件夹。
2. AppID 选「测试号」即可预览；真机调试填自己的小程序 AppID。
3. 编译 → 进「卡册」点任意卡牌「+」标记入手 → 回「卡牌」看收藏墙与统计；或进「开包」点拆包抽卡。

> 数据只存在本机微信存储，清缓存 / 换设备会丢，重要收藏建议截图备份。
> 远程图需在微信公众平台配置 `downloadFile` 合法域名（开发工具勾选「不校验合法域名」即可预览）。

## 开包功能怎么玩

「开包模拟」让卡牌册具备「拆包」体验，抽到的卡直接点亮收藏册：

1. 进「开包」页，点中央卡包「点击拆包」（每包 5 张，包内不重复）。
2. 翻牌动画后展示结果卡：`NEW`（首次抽到，已写入收藏）或 已拥有；每张卡标注稀有度（普通 / 传说 / 幻之）。
3. 每张卡可「详情」看卡牌信息、或「心愿♡」加入心愿单。
4. **点亮逻辑**：抽到的卡自动 `upsert` 到本地收藏（own=true），回到「卡册」即显示该卡带 ✓、进度 +1；回到「卡牌」即出现在收藏墙。
5. **概率**：普通款权重 10、传说 1.4、幻之 0.5（未拥有的再 ×4 加权），实测稀有卡低频掉落，符合「稀有难抽」直觉。

> 纯本地模拟，无付费、无真实概率公示、无虚拟货币，不触发游戏/博彩类资质。
