# 小程序案例指引 · 潮玩收藏册（双 IP 可切换）

> 对应「工具与案例」模块案例：**潮玩收藏册小程序**
> 仓库：`https://github.com/juziqishui11/Workbuddy_Place/tree/main/toy-collection-mp`

## 这个案例解决什么

把「潮玩 / 宝可梦收藏」做成可随手记录的私人收藏册小程序，主打 **双 IP 可切换**：

- **泡泡玛特**：潮玩视角，记录盲盒/手办拥有情况、系列进度、隐藏款、估值。
- **宝可梦**：图鉴视角，关都地区收录进度、传说/幻之稀有度分布。

两个 IP 共用同一套页面与存储，切换只在「设置」里点一下，数据各自独立。

## 它能演示的小程序能力

- 原生微信小程序完整骨架（app + 7 个 page + 工具模块）
- 本地存储读写（`wx.getStorageSync`）：收藏/心愿完全离线，无需服务器
- 配置驱动 UI：IP 切换即换主题色 + 换数据源，页面零改动
- 列表/卡片/进度条/表单/弹窗 等常见交互组件

## 怎么预览（3 步）

1. 装 **微信开发者工具** → 「导入项目」选 `toy-collection-mp` 文件夹。
2. AppID 选「测试号」即可预览；真机调试填自己的小程序 AppID。
3. 编译 → 进「图鉴」点任意藏品「加入收藏」→ 回「娃柜」看收藏墙与统计。

> 数据只存在本机微信存储，清缓存 / 换设备会丢，重要收藏建议截图备份。
