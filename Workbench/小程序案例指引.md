# 小程序案例指引 · 潮玩收藏册（双 IP 可切换）

> 对应「工具与案例」模块案例：**潮玩收藏册小程序**
> 仓库：`https://github.com/juziqishui11/Workbuddy_Place/tree/main/toy-collection-mp`

## 这个案例解决什么

把「潮玩 / 宝可梦收藏」做成可随手记录的私人收藏册小程序，主打 **双 IP 可切换**：

- **泡泡玛特**：潮玩视角，记录盲盒/手办拥有情况、系列进度、隐藏款、估值。
- **宝可梦**：图鉴视角，关都地区收录进度、传说/幻之稀有度分布。

两个 IP 共用同一套页面与存储，切换只在「设置」里点一下，数据各自独立。

## 它能演示的小程序能力

- 原生微信小程序完整骨架（app + 8 个 page + 工具模块，含独立抽卡页）
- 本地存储读写（`wx.getStorageSync`）：收藏/心愿完全离线，无需服务器
- 配置驱动 UI：IP 切换即换主题色 + 换数据源，页面零改动
- 列表/卡片/进度条/表单/弹窗 等常见交互组件
- **模拟抽卡包**：加权随机抽卡（隐藏款低概率、未拥有加权推进图鉴），翻牌动画，抽到的卡自动点亮收藏册

## 怎么预览（3 步）

1. 装 **微信开发者工具** → 「导入项目」选 `toy-collection-mp` 文件夹。
2. AppID 选「测试号」即可预览；真机调试填自己的小程序 AppID。
3. 编译 → 进「图鉴」点任意藏品「加入收藏」→ 回「娃柜」看收藏墙与统计。

> 数据只存在本机微信存储，清缓存 / 换设备会丢，重要收藏建议截图备份。

## 抽卡功能怎么玩

「模拟抽卡包」让收藏册具备「抽盒/开包」体验，抽到的卡直接点亮收藏册（对标宝可梦卡牌收藏工具的抽卡 + 脑力开发馆的开卡包）：

1. **入口 1 —— 首页横幅**：「🎁 抽卡开门」点进去，默认从第一个系列抽。
2. **入口 2 —— 图鉴系列头**：每个系列右侧「🎲 抽一抽」，直接对该系列抽。
3. **抽卡页操作**：
   - 顶部系列切换条（含「全部系列」可跨系列抽）。
   - 「抽一张」单抽；「抽一包 (5)」连抽 5 张（包内不重复）。
   - 翻牌动画后展示结果卡：`NEW 点亮 ✦`（首次抽到，已写入收藏）或 `重复`（已拥有）。
   - 每张卡可「详情」看藏品信息、或「心愿♡」加入心愿单。
4. **点亮逻辑**：抽到的卡自动 `upsert` 到本地收藏（own=true），回到「图鉴」即显示该系列进度 +1、瓦片带 ✓；回到「娃柜」即出现在收藏墙。
5. **概率**：隐藏款权重 0.6、常规款 10（未拥有的再 ×4 加权），实测 5000 次单抽隐藏款仅约 1.2%，符合盲盒「隐藏难抽」直觉。

> 纯本地模拟，无付费、无真实概率公示、无虚拟货币，不触发游戏/博彩类资质。
