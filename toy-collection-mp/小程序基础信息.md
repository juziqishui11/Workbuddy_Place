### 备案备注文案（20–200 字，可直接复制）

> 潮玩收藏册是一款面向潮玩爱好者的个人藏品管理工具，可进行模拟抽盲盒或开卡包，支持按系列记录潮玩收藏进度、标记隐藏款与普通款、录入购入价与当前估值、自动统计收藏总价值及盈亏，并提供心愿清单管理功能。所有数据仅在用户本地设备存储，不涉及商品交易、社区互动或联网服务。

- 字数：约 130 字，符合要求。
- 前置审批项：本小程序不涉及新闻、出版、宗教、医疗、金融、教育、视听等内容，**无需前置审批**，保持「未填写」/「以上都不涉及」即可。
- 服务器/域名：纯本地运行、无后端，备案时填「无」或选择「未使用服务器」。
- ⚠️「模拟抽盲盒/开卡包」仅属娱乐化展示，不涉及真实付费抽奖、概率公示或虚拟货币，不会触发游戏/博彩类资质要求。正式审核如需说明，可强调"纯本地模拟、无现金交易"。

### 备案大致流程
1. 微信公众平台 → 设置 → 基本设置 → 去备案
2. 填写主体信息（身份证正反面、手机号、人脸识别核身）
3. 填写小程序信息、负责人信息、紧急联系人
4. 腾讯初审 → 管局审核（约 3–20 个工作日）
5. 备案成功后才能正式上线

## 五、⚠️ IP / 商标风险提示

- **小程序名称、头像、简介**中避免直接使用「泡泡玛特」「POP MART」「宝可梦」「Pokémon」等注册商标字样。
- 项目内部展示角色名（LABUBU、MOLLY、DIMOO、皮卡丘、小火龙等）在个人自用/学习/非商业案例中通常无碍，但**正式上线审核时可能被要求调整**。
- 如果仅作为 Workbench 案例或自己本地体验，**不发布到公众平台即可规避该风险**。
- 建议发布版改用原创/通用命名，例如：
  - 系列名：`怪兽系列`、`太空系列`、`精灵系列`
  - 角色名用通用描述替代

## 七、如何查看 / 修改 AppID

1. 微信公众平台登录后 → 左侧「开发」→「开发管理」→「开发设置」→ 顶部「AppID(小程序ID)」。
2. 复制后填入项目 `project.config.json`：
   ```json
   {
     "appid": "wx1a2b3c4d5e6f7g8h"
   }
   ```
3. 开发者工具重新编译即可。
