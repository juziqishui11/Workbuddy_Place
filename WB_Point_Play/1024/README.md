# 1024 码上好运

一个程序员的 1024 一日游。六块面板共用同一个「1024 工号」，点开任何一块就能玩。

纯前端、零依赖、断网可用、数据只存本机。

---

## 一句玩法

10 道二选一 → 10 位二进制 → **0–1023 的工号**。这个数字会跟着你走完下面六块面板。

---

## 六块面板

第一行「工号 4 栏 + 看板 8 栏」，第二行四块等分。**点面板任意位置就放大**，不用找按钮。

| # | 面板 | 玩什么 |
|---|---|---|
| 01 | **我的程序员设** | 10 道场景题（每个都给出具体时间、地点和一个真难选的二选一），答一题点亮一位二进制，顶部「工号生成器」把 10 位实时拼成你的编号；答完得 16 型名号 + **封神原型手办形象**、六轴技能雷达、bug 体质、掉发指数、互补搭档、1024 格阵定位（你在哪一格会呼吸闪烁，带图例）；随时可「再测一次」或「只改几道题」 |
| 02 | **今日好事看板** | 长得像告警大盘，指标全是好事：**距下班 / 今日奖金池 / 今日好事 / 连续打卡**。12 条好事像信号流一样垂直滚过，扫描线停在哪条、按一下哪条就收录；右栏按小时画**累积阶梯折线**，看得见一天攒了多少；可导出长图发群 |
| 03 | **持证上岗** | 《国家级持证摸鱼工程师》《线上救火专员》《祖传代码修复大师》《0Bug 许愿人》四证 × 四版式，改姓名/工号/部门实时预览，导出 PNG |
| 04 | **代码时光机** | 五段不同年代的代码（2008 jQuery 拼 HTML / 2012 回调金字塔 / 2015 Promise 链 / 2018 字符串拼表格 / 祖传八层 for），30 条规则对照现代写法，给出代际坐标、命中清单、**行级**并排 diff、可复制的现代化版本；也可粘自己的代码 |
| 05 | **许愿机** | 摇一条愿望当引子，或自己写一句话封存，明年再打开。祝福语按「工号 + 愿望」确定性生成，不预测任何结果 |
| 06 | **需求翻译机** | 输入产品原话（「页面再丝滑一点」「简单搞下」），翻译成**隐含需求 / 隐藏工作量 / 风险点 / 排坑提醒**四栏，附 1–5 级危险度与「黑话危险榜」；24 条规则，点一行直接翻 |

## 多人一起玩（无后端方案）

本作品不依赖服务器。想让同事的好事出现在同一块大盘上：

1. 在「今日好事看板」点 **我的票** → 复制一段票码（形如 `G0742.eyJuIjo3...`）
2. 发给同事 → 同事粘进 **并入** 框 → 两个工号的好事合成一块大盘

票码里只有工号与好事编号，不含任何个人信息。合并是单向、本地、可重复的。

## 算法（可手算复核）

### 编号

10 题按顺序生成 `b1…b10`，Q1 为最高位，`编号 = 二进制转十进制 ∈ [0,1023]`。

| 维度 | 题 | 低(0) | 高(1) |
|---|---|---|---|
| 发布胆量 `ship` | Q1/Q2 | 稳 | 莽 |
| 重构冲动 `itch` | Q3/Q4 | 忍 | 痒 |
| 评审火力 `crit` | Q5/Q6 | 放 | 挑 |
| 需求弹性 `scope` | Q7/Q8 | 刚 | 柔 |
| 装备彩蛋 `egg` | Q9/Q10 | 冰美式/深色 | 热茶/浅色 |

**平票**：某维两题和为 1 时，由该维定调题（Q1/Q3/Q5/Q7）裁定 → 每维在固定极性下恰好 2 种两位组合。

**推导**：每型 `2⁴（四维程度）× 2²（装备）= 64` 个编号，`16 × 64 = 1024`，一位不差。类型码 = `b1+b3+b5+b7`。

### 两项娱乐指数

```
bugIndex = clamp(22 + 24·ship + 18·itch + 12·scope − 14·crit + 4·(置位数 − 5), 0, 100)
hairLoss = clamp(round(bugIndex × 0.45 + crit × 22 + 咖啡依赖 × 25 + 8), 0, 100)
```

结果页会展开每一项的贡献明细，可手算核对。**均为娱乐性估算，不具任何医学或评价意义。**

### 稀有度

只数编号空间，不数人：`C(10, k)`，k 为 10 位中 1 的个数。例：3 个 1 → `C(10,3)=120`，占 11.72%。

### 本地运行

```bash
node serve.js 8125      # 推荐，两个运行时都有
# 或
python -m http.server 8125
```

打开 `http://127.0.0.1:8125/`。**必须走 http 服务**，不要双击 index.html —— `file://` 下部分浏览器会限制本地资源与 Canvas 导出。

```bash
node check.js      # 静态校验：数据完整性 / 编号穷举 / 禁用词 / CSS 括号 / DOM 引用 / 规则库
```

`smoke.js` 70 项：领工号、编号同步、工牌渲染、**形象图路径**、雷达与仪表盘、1024 格阵与图例、**已领工号 → 查看工牌**、打卡、票码往返、证书改名、时光机对照与行级 diff、摇愿望、翻译命中与兜底、路由收起、无未捕获错误。
