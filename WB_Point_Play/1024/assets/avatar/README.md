16 张封神原型形象，文件名严格用类型码：

```
0000.webp  0001.webp  0010.webp  0011.webp
0100.webp  0101.webp  0110.webp  0111.webp
1000.webp  1001.webp  1010.webp  1011.webp
1100.webp  1101.webp  1110.webp  1111.webp
```

- 规格：512×640（4:5），webp q84，单张 16–34KB，合计 351KB。
- 缺图或加载失败时自动退化为该型主色的几何占位（首字 + 渐变底），不影响任何功能。
- **换图只需替换同名文件，代码零改动。**

## 生成规范（留档）

统一 prompt 骨架：

> 潮玩手办产品摄影 / Q 版三头身大头比例 / 哑光 PVC 配半透明树脂 / 浅奶白纯色背景 + 极淡网格 + 一枚柔和彩色光晕 / 三分之四侧身 / 柔和棚拍单灯加轮廓光 / 4:5 竖幅 / 头顶留一成空白
> + 该型「配色 + 材质 + 法宝意象 + 表情」

负向词：`任何已知游戏影视角色的造型与服装、写实人脸、复杂背景、文字、logo、暗色调`。

**一致性做法**：先出 1111 杨戬作风格锚，定稿后其余 15 张以它为参考图生成（`input_fidelity=low`，只继承风格不继承身份），保证比例、背景、打光统一而角色各不相同。

**后处理**：生成图右下角带工具水印（`AI生成 / WORKBUDD`），该区域基本是纯背景，用 `prep_img.py` 以「上边缘行 + 左边缘列」做二维梯度外推填充并羽化，再裁切缩放成 512×640 webp。用法：

```bash
python prep_img.py --all                        # 处理 assets/_raw/*__raw.png
python prep_img.py <单张.png> <类型码>            # 处理单张
```
