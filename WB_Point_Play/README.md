# 重庆大富翁旅行记

> 一款「掷骰开局」的旅行规划应用 —— 把做攻略这件事，变成一局越玩越上头的游戏。

**单文件 HTML**：双击浏览器打开即用，无需安装、无需登录、断网也能跑。

## 它解决什么

出行前最烦的四件事：攻略碎片化、同行的人不好沟通、预算不透明、缺仪式感。这个应用一次给全 —— 带电话 / 地址 / 地铁路线的真实参考价酒店、往返大交通、景区门票与放票规则、本地吃食排行榜（含热度与上榜理由），全部按你填的出发地、人数、预算、天数算出来。

## 四个能力

1. **四项输入，一份成行** —— 填入出发地、人数（2–4）、预算、天数，酒店（含电话、地址与地铁路线）、交通、门票、吃食排行榜一并算清，落地即可出发。目的地固定重庆。
2. **语言判断** —— 把对方发来的"随便""你自己去吧"原样贴进去，按概率推演真实意图与危险等级（0–10），并给出此刻建议。内置 12 类句式 + 1 条兜底，未命中时不瞎猜。
3. **成就与结局** —— 行程按真实数据点亮成就墙（不随机），收官结算四种旅行结局：🏆 富甲一方 / 🎲 行程满满 / 🧳 悠然过客，外加彩蛋 **🎁 衣锦还乡**（服装、首饰、旅游商品三类各 ≥1 件且合计 ≥4 件触发）。
4. **一键成册** —— 导出 HTML / Markdown，带上图说走就走；也可直接打印。

## 三个模块

| 标签 | 内容 |
|---|---|
| 📝 旅行计划 | 出发地 / 人数 / 同行关系 / 预算 / 天数（4 项必填）+ 星座守护占卜（默认天秤座；选中天秤 / 水瓶 / 双子 / 狮子额外赠 2 张决定卡） |
| 💬 旅行缘起 | 6 轮微信实录 + JEV 脑内推演（真实意图 / 危险等级 / 建议动作），另有「语言判断」工具 |
| 🎬 旅行攻略 | 机会卡 · 景点 · 交通住宿 · 吃食排行榜 · 门票 · 避坑贴士 · 采买清单 · 行程 · 成就墙 · 旅行结局 |

## 视觉风格

大富翁棋盘 + 掷骰开局：目的地 = 棋盘、景点 = 格子、预算 = 金币、必去点 = 打卡印章、达成率 = 旅行结局。插画为复古手绘水彩风（暖米金色调），11 张全部 base64 内嵌，单文件自包含。

## 说明

- 数据全部保存在浏览器本地（`localStorage`），不上传任何服务器。
- 「语言判断」未配置 API Key 时走本地推演；配置后自动切到实时模型（面板会标注 ○ 本地推演 / ● 实时）。
- 导出 Markdown / HTML 时，图片随文档一起内嵌带走。
