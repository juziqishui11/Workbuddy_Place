# Workbuddy_Place

一个 GitHub 仓库托管**多个独立 Web 工程**，每个子目录对应一个腾讯云 **EdgeOne Pages** 项目。

## 工程列表

| 目录 | 工程 | 说明 |
|---|---|---|
| `2048/` | 2048 小游戏 | 静态页 + 边缘函数 + KV 排行榜，部署见 `2048/DEPLOY_EDGEONE.md` |

## 新增一个工程（示例 `snake/`）

1. 新建子目录（如 `snake/`），放入 `index.html` 与 `edge-functions/`。
2. 在 EdgeOne 控制台创建**新的 Pages 项目**，绑定本仓库，分支 `main`，**根目录填该子目录名**（`snake`），输出目录 `.`。
3. 各工程的边缘函数、KV 命名空间相互独立，路由互不冲突。

## 部署约定

- 每个工程 = 一个独立 Pages 项目。
- **根目录 = 子目录名**（如 `2048`），输出目录 = `.`。
- 边缘函数 `edge-functions/` 是项目根目录的相对路径，随子目录天然隔离。
- 改完根目录后需在 EdgeOne 点「重新部署」生效。
